# 决策记录：新增「区划分类」维度

- **日期**：2026-08-11
- **状态**：已批准
- **参与人**：用户、AI 智能体（Codex /root）

## 背景与问题
用户提出按「区划」口径划分使用单位：一类是市级委办局（用户所在单位为天津市应急管理局），一类是下辖各区应急管理局，还有一类是行政区划（各区/街镇等属地单位）。目前 devices 表只有 org_branch / org_category / district / town 等字段，缺少统一的区划归类口径，不利于按市、区级应急系统、属地等维度查询与统计。

## 决策
在 devices 表新增 `region_category`（区划分类）字段，自动归类规则：

| 区划分类 | 归类规则 |
|---|---|
| 区应急管理局 | 使用单位路径含「区应急管理局」（含各区局内设机构、执法大队等） |
| 市级委办局 | 业务通讯录·横向委办局，以及应急管理大类下除区应急管理局外的市应急管理局直属单位 |
| 行政区划 | 业务通讯录·各区（区/街镇/村等属地单位） |
| 其他 | 企事业单位、社会侧 |
| 待定 | 使用单位为空的记录（59 条，待用户确认归属） |

保留 org_branch / org_category / unit_path 原字段与原始路径用于追溯；CLI 新增 `--region-category` 过滤参数，导出明细新增「区划分类」列。
