# 决策记录：风险村台账入表方案

- **日期**：2026-08-11
- **状态**：已批准
- **参与人**：用户、AI 智能体（Codex /root）

## 背景与问题

用户提供《通信保障重点村应急通信方式统计V3.xlsx》（下称风险村台账），共 189 个重点风险村，分布于 6 个区。风险村是全量台账（`data/equipment.db`，5952 条设备）中的一个特殊范围，后续需要支持「仅查风险村」「排除风险村」等范围查询。当前数据库尚无风险村清单，需要设计入表方案。

## 已确认的数据口径（用户确认）

1. 联络信息（联系人、职务、联系电话）**不入表**；灾害类型**不入表**。
2. **风险类型也不入表**；区、街镇、村名（及来源行号）为入表字段。
3. 街镇名统一为全量台账标准写法：**西龙虎峪镇**、**孙各庄满族乡**。
4. 杨柳青镇 10 个街村（柒街、捌街、玖街、拾街、拾壹街、拾贰街、拾叁街、拾肆街、拾伍街、陆街）以阿拉伯数字写法（七街、八街……）记作**别名**。
5. 加字/别字村名（薄前村→大薄前村委会、于台村→于台子村委会、水泉村→北水泉村委会、车道峪村→北车道峪村委会、青池岭村→青池岭沟村委会、杨庄子村→杨庄村委会、粱后庄村→梁后庄村委会）已逐村核对，上级（区/街镇）完全一致，记作**别名**。
6. 已逐村验证：189 个风险村全部能在全量台账中找到对应设备记录（含天津铁厂街道这一街镇级单位）。

## 决策选项与对比

### 方案 A：复用/改造现有 `unit_tags` 表
- 现状：`unit_tags(unit_name, tag, remark)`，只有单位名一个键，无法表达「区/街镇/单位」三级锚点，也无法容纳天津铁厂街道（全量台账 `unit_name` 为空）这类单位。
- 需要加 `district`/`town` 列改造，且风险村清单明细（189 行）和别名映射无处安放，还需另建表。
- 结论：不推荐。

### 方案 B：新建 `risk_villages` 标准表 + `risk_village_aliases` 别名表（推荐）
- 风险村标准表以「区 + 街镇标准名 + 单位标准名」为键，与 `devices` 表的 `district/town/unit_name` 完全对齐，查询直接 JOIN，无需 LIKE。
- 别名表保存风险村台账的原始写法，支持原文 ↔ 标准名双向映射，也便于将来全量台账更新后重新比对。
- 不污染设备表，标签逻辑独立、可追溯（保留来源行号）。
- 代价：多两张表；全量台账写法变化时需用别名表辅助重匹配。

### 方案 C：直接在 `devices` 表加「是否风险村」字段
- 查询最简单，但同一单位多台设备重复标记，新增范围标签需全表扫描更新，不利于后续扩展（如「已测试村」等其他范围）。
- 结论：不推荐。

## 最终建议（方案 B）

```sql
-- 风险村标准表：键与 devices.district/town/unit_name 对齐
CREATE TABLE IF NOT EXISTS risk_villages (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    district     TEXT NOT NULL,              -- 区（与 devices.district 对齐）
    town         TEXT NOT NULL,              -- 街镇标准名（西龙虎峪镇/孙各庄满族乡等）
    village_name TEXT NOT NULL,              -- 单位标准名（与 devices.unit_name 对齐）
    source_row   INTEGER,                    -- 来源行号（风险村台账 Excel 行）
    created_at   TEXT DEFAULT (datetime('now', 'localtime')),
    UNIQUE(district, town, village_name)
);

-- 风险村别名表：台账原始写法 → 标准名
CREATE TABLE IF NOT EXISTS risk_village_aliases (
    id               INTEGER PRIMARY KEY AUTOINCREMENT,
    risk_village_id  INTEGER NOT NULL REFERENCES risk_villages(id) ON DELETE CASCADE,
    alias_town       TEXT NOT NULL,          -- 台账原始街镇写法（如 西龙虎、孙各庄）
    alias_name       TEXT NOT NULL,          -- 台账原始村名（如 拾叁街村、粱后庄村）
    UNIQUE(alias_town, alias_name)
);
```

说明：
- 天津铁厂街道在 `devices` 中是街镇级单位（`unit_name` 为空），匹配采用 `devices.unit_name = risk_villages.village_name OR (devices.unit_name = '' AND devices.town = risk_villages.village_name)` 的特殊条件。
- 查询方式：仅风险村 = `INNER JOIN`；排除风险村 = `NOT EXISTS` 子查询；风险村清单 = 直接查 `risk_villages`。
- `unit_tags` 表保留原样，供未来其他标签（如已测试村）使用，不与风险村混用。

## 影响评估

- 数据库：新增两张表，不改动 `devices` 表结构与既有数据。
- 代码：新增导入脚本、扩展 CLI 查询参数，不影响既有查询功能。
- 安全：联系人、电话等涉密字段不录入；新增表仅存区/街镇/村名与来源行号。
