# 决策记录：台账查询 skill 与预置数据库方案

- **日期**：2026-08-18
- **状态**：已实施
- **参与人**：用户、AI 智能体

## 背景与问题

README 的快速开始步骤较多，后续 Trae、Workbuddy 等 AI 助手不一定能按命令行文档高效完成台账查询。用户希望将查询流程写成 skill，并直接提供一份已确认好的数据库文件，避免新环境先导入原始台账。

## 决策

1. 新增 `equipment-query` skill：源文件保存于 `docs/skill-src/equipment-query/`，提供 CLI 查询、汇总、风险村、区划分类、基准口径和 Excel 导出流程。
2. 精简 README 快速开始：日常查询不再要求先执行三套台账导入和重建命令，改为直接查询预置数据库；导入与重建命令收敛到“数据更新”小节。
3. 将已确认脱敏的 `data/equipment.db` 作为预置数据库纳入 Git 仓库，供 AI 助手和普通用户直接使用。
4. `.gitignore` 仅放行 `data/equipment.db`，`sources/`、根目录统计表、`reports/` 依然不入库。

## 安全检查

- 数据库完整性检查通过。
- 已扫描全部文本列，未发现联系人、电话、邮箱、身份证、家庭住址等敏感字段。
- 数据库表结构本身不包含联系人、电话号码字段。

## 影响评估

- 不影响 CLI、导入脚本和既有测试流程。
- 后续更新数据时，需重新确认预置库脱敏状态后再替换 Git 内的数据库文件。
- 版本号由 0.8.0 升至 0.9.0。
