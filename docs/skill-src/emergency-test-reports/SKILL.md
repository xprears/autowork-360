# 应急通信测试简报生成

## 工作步骤

1. 定位数据源
   - 正式测试报告：项目下 `sources/测试报告/` 目录中的 docx。
   - 日常测试记录：`sources/进度资料/通信设备日周报.txt`。
   - 轮次进度：`sources/进度资料/各区测试进度.txt`。
   - 数量口径：`.project/decision-log/` 与《应急装备数量统计（内部）》基准表。

2. 选择模板
   - 日报：`assets/templates/通信测试日报模板.md`。
   - 周报：`assets/templates/通信测试周报模板.md`。
   - 测试进度：`assets/templates/测试进度模板.md`。
   - 正式 docx：项目 `sources/测试报告/应急通信装备测试报告模板.docx`，黄色高亮即占位符。

3. 提取并填写
   - 按 9 类固定设备逐行填写：卫星电话（含固移）、370MHz 手台、北斗终端、无人机、单兵图传、布控球、卫星便携站、应急通信指挥车、视频会议系统。
   - 未测试或本区域无该类设备时填 `0` 或“未测试”。
   - 保留模板章节、表格列和待跟进事项结构，替换 `{{...}}` 占位符。

4. 核对口径
   - 数量冲突时以基准表和 `.project/decision-log/` 中已确认口径为准。
   - 报告内测试数、正常数、异常数不一致时，在日报说明或待跟进事项中显式标注。

5. 输出
   - 默认输出 Markdown 至 `reports/测试报告/`；如需要微信发送，转换为纯文本 TXT 或 PDF。
   - 文件命名示例：`日报_东丽区_2026-08-12.md`、`周报_2026-08-10至2026-08-16.md`、`测试进度_第三轮_2026-08-12.md`。

6. 安全检查
   - 最终内容不得包含联系人、电话号码等涉密字段；对外使用前做脱敏检查。

## 字段说明

详细字段与表格填写规则见 `references/fields.md`，仅在需要核对字段、口径或转换格式时读取。
