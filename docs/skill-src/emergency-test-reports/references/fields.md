# 字段与口径说明

## 固定设备类别

日报、周报统一保留 9 类设备：

1. 卫星电话（含固移）
2. 370MHz 手台
3. 北斗终端
4. 无人机
5. 单兵图传
6. 布控球
7. 卫星便携站
8. 应急通信指挥车
9. 视频会议系统

某区域无该类设备或本期未测试时，对应数量填 `0`，测试日期填“未测试”，说明中写原因；不要删除整行，除非用户明确要求调整固定清单。

## 日报字段

- 填报日期：报告填写当天的日期。
- 测试区域：本日报对应区划。
- 数据来源：报告文件名及最近更新时间；如报告实际测试日期与填报日期不同，在“说明”中写清楚。
- 测试情况表：台账总数、已测试数、正常数、异常/未通过数、测试日期、异常原因及说明。
- 待跟进事项：按设备归纳未闭环事项，默认 1 至 4 项，可增加。

## 周报字段

- 报告周期：本周起止日期。
- 本周涉及区域：本周实际测试的区，多个区用顿号分隔。
- 本周汇总：按 9 类设备统计本周测试数，未测填 0 或“本周未测”。
- 每日记录：每个测试日一行，包含日期、测试区域、当日测试概况、异常情况、待跟进事项；有多个测试日时复制行。
- 本周小结：2 至 3 句话概括完成数量、主要异常及原因。
- 下周计划：按设备或区域列出滚动计划，默认 1 至 4 项。

## 测试进度字段

- 更新日期、数据来源、测试周期：按当前轮次实际填写。
- 总体进度：概括已归档区数、总体百分比和主要待补差距。
- 分区进度：固定 16 个区，区划顺序为滨海新区、河北区、西青区、红桥区、南开区、津南区、北辰区、武清区、宝坻区、河东区、河西区、宁河区、和平区、东丽区、蓟州区、静海区。
- 分类进度：保留卫星电话（含固移）、370MHz 手台、布控球、无人机、通信指挥车 5 类既有口径，新增口径时追加行。
- 本周更新：按设备类别归纳最新测试结果。
- 待闭环事项：列出未归档报告、待复核数量和待补测事项。

## 数据来源优先级

1. 各区正式测试报告（docx）
2. `sources/进度资料/通信设备日周报.txt`
3. `sources/进度资料/各区测试进度.txt`
4. 《应急装备数量统计（内部）》基准表

数量冲突时以基准表和 `.project/decision-log/` 中已确认口径为准；报告自身口径不一致时在日报中显式标注并列入待跟进事项。

## 格式转换提示

- Markdown 表格转 TXT 时，将表格改为“设备类别：总数/测试/正常/异常”的平铺文本，避免保留 Markdown 符号。
- 转 PDF 时使用本地转换工具，转换后检查中文内容无乱码、表格无越界。

## 安全要求

- 不录入联系人、电话号码、精确位置等涉密字段。
- 对外使用前做脱敏检查。
