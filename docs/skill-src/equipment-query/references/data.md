# 数据说明

## 数据表

- `devices`：设备台账主表，当前 5952 条，含设备类型、品牌型号、单位路径、区、街镇、单位、状态、来源信息等。
- `risk_villages`：风险村清单，当前 189 个村，仅存区、街镇、村名与来源行。
- `risk_village_aliases`：风险村原始写法别名。
- `equipment_benchmark`：设备数量基准表，当前 174 条口径记录，按设备类型、统计单位/区、口径存储。
- `unit_tags`：预留的单位标签表，当前为空。

## 口径注意事项

- 联系人、电话、灾害类型等涉密字段不入表；查询和导出时不得补录敏感信息。
- 风险村设备与全量台账存在 2 处已知差异：大田村 370 手台预置 1 台但全量挂在汉沽街道级；桃园村北斗全量实际 1 台而台账预置 0。属于预置数与实际配发数的正常差异。
- 无人机按“设备类型 + 区”汇总入库至 `equipment_benchmark`，不写入 `devices` 逐台明细。
- 370MHz 沿用配置/可用/配发/自购口径，不新增其他字段。
- 数量冲突时以《应急装备数量统计（内部）》基准表与 `.project/decision-log/` 中已确认口径为准。
