# 应急通信装备测试报告固定模板使用说明

## 文件位置

- 模板文件：`sources/测试报告/应急通信装备测试报告模板.docx`
- 生成脚本：`scripts/make_test_report_template.py`

`sources/` 按项目安全规范默认不进 Git，模板文件由脚本可重复生成，正式报告请自行保管。

## 生成方式

```bash
python3 scripts/make_test_report_template.py \
  --source "/原始报告路径/应急通信装备测试报告-20260529(1).docx"
```

默认输出到 `sources/测试报告/应急通信装备测试报告模板.docx`，可用 `--output` 指定其他路径。

## 填写规则

- 黄色高亮即待填字段，填写完成后可取消高亮再排版。
- 常用占位符包括：组织单位、覆盖区数量、覆盖单位层级、设备类型清单、测试设备总数、测试开始/结束日期、各设备类型的持有总数/测试数/正常数/异常数、无设备区清单、问题描述与示例、解决建议、建议一/二、报告日期。
- 故障与未接入清单表默认保留 3 至 6 个样例行与合计行；行数不足时可复制表头行下的样例行插入，保留原表格边框与字体。
- 表7 应急指挥通信车明细清单、表8 应急指挥通信车配置清单属于固定参考清单，保留原内容；车辆或配置发生变化时请同步维护。

## 相对原文件的修正

- 表5 标题由“单兵图传未接入清单”更正为“无人机未接入清单”，与无人机小节对应。
- 表6 标题由“未集成清单”更正为“未建立通信清单”，与表内“无法建立通信数量”对应。

## 安全提示

填写模板时请勿录入联系人电话等涉密字段；对外使用前先做脱敏检查。
